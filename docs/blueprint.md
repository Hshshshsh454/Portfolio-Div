# **App Name**: PortfolioPilot

## Core Features:

- Portfolio Fetch: Fetch and display portfolio content from the provided URL: https://portfolio-delta-brown-29.vercel.app/.
- Customization Options: Provide options for users to customize the visual style and layout of the portfolio.
- AI Style Guide: Generate a UI style guide that assists users to refine the existing website styles, and to help produce a more cohesive, personalized presentation of their work; using a tool to decide when or if a specific piece of information will be most beneficial.

## Style Guidelines:

- Primary color: Soft coral (#F08080) to bring a friendly, approachable vibe.
- Background color: Pale peach (#FAF0E6), subtly different in hue for gentle contrast.
- Accent color: Muted rose (#BC8F8F), adds sophistication and emphasizes calls to action.
- Headline font: 'Playfair', serif with a fashionable, high-end feel; body font: 'PT Sans', a humanist sans-serif.
- Simple, elegant line icons to highlight portfolio sections and features.
- Clean and structured layout with clear visual hierarchy for easy navigation.
- Subtle fade-in and transition effects to enhance user experience without being distracting.
